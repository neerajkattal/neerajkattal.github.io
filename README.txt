# Neeraj Kattal - Portfolio (Warm Beige Editorial theme)

Same animated portfolio structure (hero typing, scroll-reveal, timeline, project filters,
dark/light toggle) with a custom 'Warm Beige Editorial' color palette applied to both modes.

Dark mode accents: #d4a373, #9caf88
Light mode accents: #a9744f, #6b8f5e

## Deploy
Copy index.html, css/, js/, assets/ into your neerajkattal.github.io repo root, replacing old files.
Commit and push.
